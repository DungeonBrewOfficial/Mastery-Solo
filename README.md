# Mastery Solo

The Solo Game, the wilderness campaign Jon built on the school bus around 1998–2001, rebuilt on Mastery.

One player runs a party of four through a world that is generated as they explore it. They wander, fight, find places worth reaching, and come home to heal, repair, and set out again. A **run** is one hero's career, from setting out to death or retirement. A **dynasty** is one world and the line of heroes who walk it. When a dynasty ends, the next begins on a new map.

The design is meant to work on paper, with dice, pencils, and the Mastery rulebooks. A VTT can help, but it isn't required.

## What's here

- `sources/` holds the restoration of the original game: the reconstruction record (what was remembered, inferred, and guessed) and *The Solo Game as Played*. These are the attested starting point. Nothing in `design/` changes them.
- `design/` holds the new procedures, one file per piece, numbered in reading order.
- `playtests/` holds playtest and dry-run reports.
- `DECISIONS.md` lists the rulings Jon has made, with dates, and the questions still open.

## Tags

Design files tag their claims, following the convention in the reconstruction record:

- **[M]** Mastery as written. The rule lives in a named Mastery chapter and this design uses it unchanged.
- **[S]** From the Solo Game, attested in `sources/`.
- **[N]** New to this design. Proposed, and standing only until corrected.
- **[?]** Open. Needs a ruling before it can be finished.
